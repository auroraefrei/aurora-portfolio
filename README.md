# 冯远帆个人主页

这是用于 GitHub Pages 的静态个人主页。所有图片均使用本人提供的素材，网站没有依赖外部图片或第三方脚本。

## 文件
- `index.html`：主页结构与内容
- `styles.css`：响应式样式，适配桌面与移动端及系统明暗主题
- `script.js`：移动导航与照片放大预览
- `assets/`：用户提供照片的裁切与压缩版本
- `resume.pdf`：依据最新上传简历内容重新排版的 PDF，经历和时间以原简历为准
- `resume-original.docx`：原始 Word 简历副本

## 发布到 GitHub Pages
1. 将压缩包内所有文件解压到一个 GitHub 仓库的根目录。
2. 在仓库 Settings → Pages 中选择从分支部署，并将目录设置为 `/ (root)`。
3. 等待 GitHub Pages 构建完成后，页面即可通过 GitHub 提供的网址访问。
